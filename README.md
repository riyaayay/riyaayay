### `featured projects`

> ### ✦ [NYAYA](https://github.com/riyaayay/nyaya)
> AI accountability platform that scans lending datasets for proxy discrimination and explains automated rejections to the people they affect, in Hindi.
>
> `Python` `FastAPI` `React` `Gemini 1.5 Pro` `SHAP` `BigQuery`
>
> Built for Google Developer Groups — Solution Challenge 2026.
>
> [View project →](https://github.com/riyaayay/nyaya) · [Live demo →](https://nyaya-seven.vercel.app/)

<br/>

> ### ✦ [ProofClose](https://github.com/riyaayay/proofclose)
> A settlement-reconciliation controller that proves — or explicitly refuses to prove — the link between settlement, ledger and bank records, with a typed audit trail and zero tolerance for false closures.
>
> `Next.js` `TypeScript` `SQLite`
>
> 97/120 rows auto-closed · **100%** close precision · **0** false closures, enforced by CI *(synthetic evaluation cohort)*
>
> [View project →](https://github.com/riyaayay/proofclose) · [Live demo →](https://proofclose.vercel.app/)

<br/>

> ### ✦ [VoltAgent](https://github.com/riyaayay/voltagent)
> Voice-first, verified RAG copilot for EV-charging field technicians. Retrieves from protocol specs and hardware manuals, then runs a dedicated verifier agent over every claim before it's spoken back in Hindi or English — low-confidence answers fall back to the raw source instead of guessing.
>
> `Python` `FastAPI` `LangGraph` `Elasticsearch` `Qdrant`
>
> [View project →](https://github.com/riyaayay/voltagent)

<br/>

> ### ✦ [PolarSolarNet](https://github.com/riyaayay/HALO-CME-Prediction)
> A hybrid CNN + CatBoost ensemble that detects Halo Coronal Mass Ejections from SOHO/LASCO coronagraph images, using a polar-coordinate transform to capture their full 360° angular signature.
>
> `Python` `PyTorch` `CatBoost` `OpenCV`
>
> AUC-ROC ≈ 0.948 across Solar Cycles 23–25 · submitted to ACM Multimedia 2026 *(under review)*
>
> [View project →](https://github.com/riyaayay/HALO-CME-Prediction)

<br/>

> ### ✦ [WordDuel](https://github.com/riyaayay/worduel-complete)
> Real-time multiplayer word game — a Go backend using goroutines and channels for matchmaking and live sessions, a trie for word validation, WebSockets for sync, and a native Kotlin/Compose Android client.
>
> `Go` `Kotlin` `WebSockets`
>
> p95 move round-trip latency ≈ 12ms under an 80-client load test
>
> [View project →](https://github.com/riyaayay/worduel-complete)

<br/>

> ### ✦ [Brain Tumor Classifier](https://github.com/riyaayay/brain-tumour-prediction)
> An EfficientNetB4 transfer-learning classifier for MRI scans across glioma, meningioma, pituitary and no-tumor classes, tuned with cross-validation, augmentation and early stopping.
>
> `Python` `TensorFlow` `Keras`
>
> 90%+ test accuracy
>
> [View project →](https://github.com/riyaayay/brain-tumour-prediction)
